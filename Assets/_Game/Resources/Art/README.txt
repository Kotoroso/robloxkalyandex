Сюда можно положить свои картинки (PNG, прозрачный фон, 512x512) — игра возьмёт их вместо нарисованных кодом:
  dragon_<id>.png   — дракон (id из GameConfig.Dragons: эксклюзивы 36..41)
  egg_<тир>.png     — яйцо тира (0..11), egg_premium.png — Драконье яйцо
В настройках импорта PNG включи Read/Write не нужно; тип — Default (Texture2D).
