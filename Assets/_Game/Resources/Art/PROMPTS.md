# Промпты для картинок (ChatGPT / DALL·E, Шедеврум, Kandinsky, Midjourney)

Как использовать:
1. Для каждой картинки вставь в генератор строку STYLE и строку конкретного объекта.
2. Нужен PNG с прозрачным фоном. Если генератор не умеет прозрачный фон, проси сплошной белый (#FFFFFF), я уберу его сам.
3. Сохрани файл под указанным именем в эту папку (Assets/_Game/Resources/Art/) или просто пришли картинки мне — я разложу и подключу.
4. Игра сама подхватит картинки вместо нарисованных кодом (магазин, рулетка, инвентарь, меню драконов).

## Порядок важности
1) донатные драконы 36–41 и Драконье яйцо; 2) иконки интерфейса; 3) баннеры магазина и трейлы; 4) обычные драконы и яйца тиров.

## Общий стиль для драконов (добавляй к каждому промпту дракона)
```
STYLE: cute chunky 3D game icon of a baby dragon, Roblox / LEGO blocky toy style, glossy plastic, soft studio lighting, big friendly eyes, bold clean shapes, three-quarter side view facing right, whole body visible and centered, vibrant saturated colors, transparent background, no text, no border, no shadow on the ground, 1024x1024 PNG
```
