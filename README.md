# Укради Дракона (Dragon Heist): роблокс-стайл игра для Яндекс Игр на Unity

Кради яйца драконов у брейнротов, выращивай их на грядках базы, качай скорость на беговых дорожках, перерождайся.

## Как запустить

1. Unity Hub → **Add → Add project from disk** → выбери папку репозитория.
   Подойдёт Unity **2021.3 LTS / 2022.3 LTS / Unity 6** с модулем **WebGL Build Support**.
   Если Hub спросит версию, выбирай любую установленную. Папки `Packages/` и остальные файлы `ProjectSettings/` Unity создаст сама.
2. После открытия проекта сама создастся сцена `Assets/_Game/Scenes/Main.unity`.
   Если Unity предложит включить режим ввода «Both» и перезапуститься, соглашайся.
3. Нажми **Play**. Весь мир, персонаж, брейнроты, драконы, UI и музыка создаются кодом, руками в сцене ничего собирать не нужно.

## Сборка для Яндекс Игр

1. Меню **Dragon Heist → 1. Настроить проект под Яндекс Игры**: переключает платформу на WebGL, ставит шаблон `Yandex`, Gzip + decompression fallback, Gamma, strip.
2. Меню **Dragon Heist → 2. Собрать для Яндекс Игр**: сборка в `Builds/YandexWebGL`.
3. Заархивируй **содержимое** папки (чтобы `index.html` лежал в корне zip) и загрузи в [консоль разработчика Яндекс Игр](https://games.yandex.ru/console/).

Из командной строки:
```
Unity -batchmode -projectPath . -executeMethod DragonHeist.EditorTools.YandexBuild.BuildBatch -quit -logFile build.log
```

## Управление

| | ПК | Телефон |
|---|---|---|
| Ходьба | WASD / стрелки | плавающий джойстик (левая часть экрана) |
| Прыжок | Пробел | кнопка «Прыжок» |
| Действие (украсть / ускорить / продать / купить) | зажать **E** | зажать кнопку-подсказку справа |
| Камера | зажать ПКМ + мышь, колесо = зум | свайп справа, щипок = зум |

## Механики

- **Зоны тиров.** На дороге 7 зон: Обычное → Необычное → Редкое → Эпическое → Легендарное → Мифическое → Секретное. В каждой на пьедестале лежит яйцо, его охраняют брейнроты (Тун Тун Сахур, Лирили Ларила, Бомбардиро Крокодило, Тралалеро Тралала, Брр Брр Патапим, Капучино Ассасино, Ла Вака Сатурно). Чем дальше зона, тем быстрее и многочисленнее охрана. Над аркой зоны написана скорость охраны.
- **Кража.** Зажми E у яйца и беги на базу. Если брейнрот догонит, яйцо вернётся на место, а тебя отправит на спавн.
- **Грядки.** Украденное яйцо само садится на свободную грядку. Время роста зависит от тира: от 20 сек до 1.5 часа. Если свободных грядок нет, яйцо ждёт в инвентаре.
- **Реклама −90%.** Подойди к растущему яйцу и зажми действие: после rewarded-видео оставшееся время сокращается на 90%.
- **Драконы.** 14 штук, по 2 на тир. У каждого свои статы: +% скорости, монеты/сек, +% к прокачке, +прыжок. Дракона можно продать.
- **Беговые дорожки.** Беги вперёд по дорожке, и качается скорость. Всего 5 дорожек (×4 … ×1000/сек), дорогие открываются за монеты и перерождения.
- **Перерождения.** Сбрасывают монеты и скорость. Взамен дают +50% к доходу и прокачке, +1 грядку и открывают новые дорожки.
- **Оффлайн-доход.** Пока тебя нет, драконы приносят 50% дохода (максимум за 2 часа).
- **Сохранения.** Локально (PlayerPrefs) и в облаке Яндекса (`player.setData`). При загрузке берётся более свежее.

## Требования Яндекса, которые уже сделаны

- `LoadingAPI.ready()` после загрузки, `GameplayAPI.start/stop` вокруг рекламы.
- Звук и время на паузе во время рекламы и при сворачивании вкладки.
- Полноэкранная реклама не чаще 90 сек: после перерождения и не чаще раза в 3 минуты при поимке.
- Язык RU/EN берётся из `environment.i18n.lang`.
- Весь звук и графика генерируются кодом, чужих ассетов нет, поэтому проблем с авторскими правами на модерации быть не должно.

## Производительность (средние Android)

- Статика мира объединяется в батчи (`StaticBatchingUtility`), меши примитивов общие, коллайдеры только там, где нужны.
- На мобилках отключены тени и MSAA, `devicePixelRatio` ограничен 1.25, цель 60 FPS.
- Текстуры процедурные и крошечные (64×64), билд очень лёгкий.

## Где что лежит

```
Assets/_Game/Scripts/Core      конфиг баланса (GameConfig), экономика (GameManager), сохранения, локализация, точка входа
Assets/_Game/Scripts/World     генерация карты, роблокс-модели из кубиков (Blocky), материалы/текстуры студов
Assets/_Game/Scripts/Gameplay  грядки, пьедесталы с яйцами, ИИ брейнротов, беговые дорожки
Assets/_Game/Scripts/Player    персонаж, камера, ввод
Assets/_Game/Scripts/UI        HUD, панели, мобильный джойстик
Assets/_Game/Scripts/Yandex    C#-мост к Yandex SDK
Assets/Plugins/WebGL           YandexBridge.jslib
Assets/WebGLTemplates/Yandex   index.html с подключением /sdk.js
```

Баланс (время роста, скорость охраны, цены, статы драконов) настраивается в `Assets/_Game/Scripts/Core/GameConfig.cs`.
